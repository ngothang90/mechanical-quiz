Mechanical Quiz V5

Changes from V4:
1. Employee code + full name are saved in browser localStorage. The delete button was removed; users can clear browser data manually if needed.
2. Public/Admin dashboard: one chart per topic. Each topic chart shows each person's unique correct questions divided by total questions in that topic. The right column shows how many times that person completed that topic.
3. Ranking is split into two tables: (1) number of attempts, (2) unique correct questions across the entire question bank / total bank.
4. Firebase project: mechanical-quiz-eec08.
5. Uses Firebase Anonymous Authentication for employees and Email/Password for admin.

Deploy: upload the contents of this folder to GitHub Pages or Firebase Hosting.
